# UDesigner Catalogue Improvements\n\nAccurate product-style visuals for the remodel catalogue.\n\n## Files\n- `frontend/src/lib/productCatalogs.js` \u2014 WINDOW, APPLIANCE, TILE, HARDWARE, SHOWER catalogues with `visual` keys\n- `frontend/src/lib/productVisuals.js` \u2014 `getProductThumbnail(visualKey)` returns data-URI SVGs that depict the actual product (aluminum-clad, wood casement, white subway, matte-black pull, frameless glass, etc.)\n- `frontend/src/components/ProductPicker.jsx` \u2014 ready-to-use picker with tier filter and \u201cbrowse by look\u201d\n\n## Usage\n```jsx\nimport ProductPicker from \"./components/ProductPicker\";\nimport { getProductThumbnail } from \"./lib/productVisuals\";\n\n<ProductPicker category=\"windows\" onPick={(item) => console.log(item.visual)} />\n```\n\nUsers see the real product look, not brand text or generic swatches.\nPlacement stays in the existing onPick callback so other workflows are untouched.\n
